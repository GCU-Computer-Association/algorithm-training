# DFS 与 BFS 模板 —— 零基础讲解

## 一、搜索到底在干什么

很多题目可以想象成"在一张地图上走路"：你站在起点上，
要找出能走到哪些格子、能不能走到终点、最少要走几步……
"按什么顺序把格子走一遍"，就是搜索策略。
最常用的两种策略：DFS（一条路走到黑）和 BFS（像水波一圈圈扩散）。

## 二、DFS：一条路走到黑

想象走迷宫时认死理的人：每到一个路口就挑一条路一直往前走，
走不通（撞墙/死路）就退回上一个路口，换一条路再试，直到试完所有路。
写法：递归（函数自己调用自己）。
"退回"在代码里是自动发生的：递归函数返回时，就自然回到了上一层。
适合：问"有没有路"、"有几个连通块"、"把所有方案列出来"。

## 三、BFS：像水波一样一圈圈扩散

想象一滴水滴到水面上，波纹一圈一圈向外扩：
先走完"离起点 1 步"的所有格子，再走"离起点 2 步"的所有格子……
写法：用队列（queue：先进先出，像排队一样，先来的先处理）。
为什么能求最短：因为"第几圈 = 几步"，某个点第一次被走到时，
所在的圈数就是到达它的最少步数。
适合：问"最少几步"、"最短距离"（要求每一步代价相同）。

## 四、回溯 = DFS + 撤销（恢复现场）

回溯也是一种 DFS，只是每试完一条路，要把刚才的选择"撤销"掉，
恢复到没选之前的状态，再去试下一条路。
这是列全排列、N皇后等"把所有方案都找出来"题型的核心。

## 五、模板怎么选（先对答案再套模板）

| 题目问法 | 选哪个模板 | 特点 |
| --- | --- | --- |
| 能不能到 / 有几个 | DFS（模板一、二） | 代码短 |
| 最少几步 / 最短路径 | BFS（模板四） | 一圈圈扩散 |
| 一共有多少种方案 | 回溯（模板三） | 枚举所有方案 |

## 六、所有模板通用的 3 个防错点

1. 必须记录 visited（来过没有）：没有它会在环里绕圈甚至死循环。
   （模板二把 '1' 改成 '0'，本身就是一种 visited 标记）
2. 先判断"越界"，再判断"能不能走"：顺序写反会数组越界。
3. BFS 里 visited 在【入队时】就标记，而不是出队时：
   否则同一个点会被反复入队，队列爆炸。

## 七、复杂度速查表

| 场景 | 复杂度 | 说明 |
| --- | --- | --- |
| 图/树的 DFS | `O(V+E)` | V = 节点数，E = 边数 |
| 网格 DFS / BFS | `O(M*N)` | M 行 N 列，每个格子最多访问一次 |
| 回溯：排列类 | `O(N*N!)` | 共 N! 种排列，每种长度 N |
| 回溯：子集/组合类 | `O(2^N)` | 共 2^N 种子集 |

记忆法：图按"点+边"算，网格按"格子数"算，
回溯按"方案总数 × 每份方案的复制代价"算。

> 进阶提示：图特别深时递归 DFS 可能爆栈（递归层数太多），
> 可改成"自己用栈模拟"的非递归写法。

## 模板一：通用图 / 树的 DFS

**思路（3 步）：**

1. 空节点直接返回（防御性判断）。
2. 已经访问过的点直接返回 —— 防止在环里绕圈。
3. 标记当前点"已访问"，然后对每个邻居递归调用 dfs。

**时间复杂度：** `O(V+E)`。V 为节点数，E 为边数。
理由：每个节点最多访问 1 次（V 次），每条边最多被看 2 次（E 次）。

**适用题型：**

1. 图的连通性：判断两个节点是否连通、计算无向图的连通分量的个数
2. 拓扑排序：课程表问题（判断是否有环、输出学习顺序等）
   —— 注意：拓扑排序需要把 visited 改成 3 种状态
   （0=没访问，1=正在访问，2=访问完），才能判断环
3. 树的遍历：二叉树的前/中/后序遍历、寻找二叉树的所有路径

```cpp
struct Node
{
    ll val;
    vector<Node*> neighbors;
};

void dfs(Node* node, unordered_set<Node*>& visited)
{
    if (!node)return;                        // 空节点：防御性判断
    if (visited.count(node))return;          // 访问过就返回，防止在环里绕圈

    visited.insert(node);                    // 先标记"来过"，再继续走
    for (auto neighbor : node->neighbors)dfs(neighbor, visited);  // 每条边都试着走
}
```

## 模板二：网格上的 DFS（岛屿数量）

**思路（3 步）：**

1. 越界 / 是水（'0'）就直接返回 —— 这是递归的出口。
2. 把当前陆地 '1' 改成 '0'：这既是"标记访问过"，又是"把这个岛沉掉"，
   之后永远不会再走到这块地，所以不用单独的 visited 数组。
3. 向上下左右 4 个方向递归，把和当前点连成一片的陆地全部沉掉。
   主函数里每遇到一个 '1' 就调用一次 dfs，调用总次数 = 岛屿数量。

方向数组：dx = { -1,1,0,0 }，dy = { 0,0,-1,1 }
依次表示：上(-1,0)、下(1,0)、左(0,-1)、右(0,1)。

> [注意] 原模板写成 dx = { -1,-1,0,0 } 是错的：缺少"下"和"右"两个方向！

**时间复杂度：** `O(M*N)`。M 为网格行数，N 为网格列数。
理由：每个格子最多被访问 1 次（访问过就变成 '0' 了）。

**适用题型：**

1. 连通块的统计：岛屿数量、被围绕的区域
2. 面积/周长计算：最大岛屿面积/周长（在 dfs 里计数即可）
3. 填充问题：图像渲染（把连成一片的颜色改成新颜色）
4. 迷宫寻路（非最短）：判断是否有出路（不求最小步数）

```cpp
class Solution
{
    ll dx[4] = { -1,1,0,0 };      // 上下左右 4 个方向的行偏移（原来 {-1,-1,0,0} 是错的）
    ll dy[4] = { 0,0,-1,1 };      // 对应的列偏移

    void dfs(vector<vector<char>>& grid, ll r, ll c)
    {
        ll m = grid.size(), n = grid[0].size();   // 若 grid 可能为空，这里要先判空再取 grid[0]
        if (r < 0 || r >= m || c < 0 || c >= n || grid[r][c] == '0')return;  // 越界或水：返回

        grid[r][c] = '0';                        // 沉掉这块陆地 = 标记已访问

        for (ll i = 0; i < 4; i++)dfs(grid, r + dx[i], c + dy[i]);  // 向 4 个方向扩散
    }
};
```

## 模板三：回溯（排列 / 组合 / 子集）

**思路（一句话）：** 把所有可能的方案想象成一棵"决策树"，
每个位置都尝试各种选择，试完一条路就撤销刚才的选择（恢复现场），
再试下一条路。

**以全排列为例，3 步：**

1. 出口：path 已经凑满 nums.size() 个数 = 得到一个完整排列，保存并返回。
2. 每个位置遍历所有候选：used[i] 标记"用没用过"，用过的跳过。
3. 选它 -> 递归 -> 撤销（pop_back + used[i] = false）。
   "撤销"这步叫恢复现场，是回溯的核心！
   不恢复的话，下一条路会拿到上一条路留下的脏数据。

**时间复杂度：**

- 排列类：`O(N*N!)` —— 共 N! 种排列，每种长度 N，复制进答案要 O(N)；
- 子集/组合类：`O(2^N)` —— 共 2^N 种子集，每个元素"选或不选"。

**适用题型：**

1. 排列：全排列、字符串排列
2. 搜索与约束满足：N皇后、解数独、单词搜索（在二维矩阵中找单词）
3. 组合/子集：找子集、组合总和、电话号码的字母组合

```cpp
void backtrack(vector<ll>& nums, vector<ll>& path, vector<bool>& used, vector<vector<ll>>& res)
{
    if (path.size() == nums.size())           // 出口：凑满一个完整排列
    {
        res.push_back(path);                  // 保存答案（push_back 会复制一份 path）
        return;
    }

    for (ll i = 0; i < nums.size(); i++)      // 每个位置都试着放每个数
    {
        if (used[i])continue;                 // 用过的数跳过

        path.push_back(nums[i]);              // 选：把 nums[i] 放进当前排列
        used[i] = true;                       // 标记已使用

        backtrack(nums, path, used, res);     // 递归：去填下一个位置

        path.pop_back();                      // 撤销：恢复现场（回溯核心）
        used[i] = false;
    }
}
```

## 模板四：BFS 最短路径 / 最少步数

**思路（为什么 BFS 第一次到终点就是最短）：**
BFS 是一圈一圈走的：第 0 圈只有起点，第 1 圈是走 1 步能到的所有点，
第 2 圈是走 2 步能到的所有点……"圈数 = 步数"。
所以某个点第一次被遇到时，所在圈数就是到达它的最少步数。

**代码 4 个要点：**

1. 队列 + step 分层：每圈开始先 size = q.size() 记下本圈有多少个点，
   本圈全部弹完后 step+1。
2. visited 在入队时立刻标记（不是出队时）！否则同一个点会被重复入队。
3. 每弹出一个点，先判断是不是终点（同一圈内先弹出来 = 先遇到）。
4. 方向数组 dx = { -1,1,0,0 }, dy = { 0,0,-1,1 }。

> [注意] 原模板写成 { -1.1, 0.0 } 是笔误：小数不能赋给整数数组，
> 实际会变成 { -1,0,0,0 }，第二个方向变成"原地不动"，还少了"下"！

**时间复杂度：** `O(M*N)`（网格上）。M 为网格行数，N 为网格列数。
一般图上是 `O(V+E)`。理由：每个点最多入队 1 次，每条边被看 1 次。

**适用题型：**

1. 无权图的最短路径（每一步代价相同）：迷宫到达终点的最小步数、二叉树的最小深度
2. 状态转移求最小操作数：打开转盘锁（力扣 752）、单词接龙（力扣 127）

```cpp
ll bfs_shortest_path(vector<vector<ll>>& grid, ll start_r, ll start_c, ll target_r, ll target_c)
{
    ll m = grid.size(), n = grid[0].size();
    queue<pair<ll, ll>> q;
    vector<vector<bool>> visited(m, vector<bool>(n, false));  // visited 数组

    q.push({ start_r,start_c });              // 起点入队
    visited[start_r][start_c] = true;         // 入队的同时标记，防止重复入队

    ll step = 0;                              // 当前步数（= 第几圈）
    ll dx[4] = { -1,1,0,0 }, dy[4] = { 0,0,-1,1 };  // 上下左右（原来 {-1.1,0.0} 是错的）

    while (!q.empty())
    {
        ll size = q.size();                   // 本圈有多少个点：分层的关键！
        for (ll i = 0; i < size; i++)         // 只处理这一圈的点
        {
            auto curr = q.front();
            ll r = curr.first, c = curr.second;
            q.pop();

            if (r == target_r && c == target_c)return step;  // 第一次遇到终点 = 最少步数

            for (ll k = 0; k < 4; k++)        // 向 4 个方向扩展
            {
                ll nr = r + dx[k], nc = c + dy[k];
                // 越界 / 已访问直接跳过；若有墙（如 grid 里 1 表示墙），
                // 在这里再加一个条件 && grid[nr][nc] != 1
                if (nr >= 0 && nr < m && nc >= 0 && nc < n && !visited[nr][nc])
                {
                    visited[nr][nc] = true;   // 入队就标记
                    q.push({ nr,nc });
                }
            }
        }
        step++;                               // 一圈处理完，步数 +1
    }
    return -1;                                // 队列空了还没到终点：走不到，返回 -1
}
```

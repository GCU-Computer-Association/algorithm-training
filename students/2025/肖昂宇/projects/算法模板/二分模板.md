# 二分查找 模板（详细讲解版）

## 一、讲解思路：什么是二分查找

想象你在字典里查一个单词。字典里的单词是按字母顺序排好的，
你绝不会从第一页一页页往后翻——而是先翻到中间，
看看要找的单词在中间这页之前还是之后，只留下可能的那一半，
再在这一半的中间继续翻。每翻一次范围缩小一半，几下就找到了。

二分查找就是把"翻字典"的过程搬到数组上，它只做一件事：
每次取当前区间的中间位置 `mid`，和目标值比较一次，
然后放心地丢掉不可能的一半。

**前提条件（最重要！）：数组必须有序（从小到大，或从大到小）。**
如果数组是乱序的，二分的结果没有意义。

核心三步（下面都以"数组从小到大排列"为例）：

1. 设当前查找区间为 `[left, right]`，取中间位置 `mid`；
2. 比较 `a[mid]` 和要找的值 `num`，只有三种可能：
   - `a[mid] == num` -> 找到了，返回下标 `mid`；
   - `a[mid] < num` -> `num` 在 `mid` 的右边，把 `left` 移到 `mid + 1`（丢掉左半段）；
   - `a[mid] > num` -> `num` 在 `mid` 的左边，把 `right` 移到 `mid - 1`（丢掉右半段）；
3. 重复 1、2 步。区间每轮至少缩小一半，
   直到找到；或者区间空了（`left > right`），说明数组里没有 `num`，返回 -1。

为什么敢"丢掉一半"？
因为数组递增：如果 `a[mid]` 比 `num` 小，那么 `mid` 左边所有元素
都比 `a[mid]` 还要小，更不可能是 `num`，可以整段放心丢弃。
这是二分查找成立的关键，也是它必须要求有序的原因。

## 二、时间复杂度

每比较一次，查找范围缩小一半。
问：n 个元素最多缩几轮会缩到 1 个？就是"n 连续除以 2，几次变成 1"，
这个次数约为 log2(n)，所以时间复杂度记作 O(logn)。

对比暴力做法（从头到尾一个个找）：O(n)。
当 n = 1000000 时：
- 暴力：最坏要比较 1000000 次；
- 二分：最多只要约 20 次。

这就是为什么"有序 + 查找"的题优先想二分。

空间复杂度：
- 迭代版本只用了几个变量，O(1)；
- 递归版本每一层递归都占用函数调用栈，递归深度 O(logn)，所以空间 O(logn)。

## 三、适用题型（什么时候想到二分）

1. 在有序数组里查找某个值是否存在、返回下标（最基础的用法）。
2. 查找边界："第一个 >= x 的位置"、"第一个 > x 的位置"（等价于手写 `lower_bound` / `upper_bound`，常配合统计出现次数）。
3. 二分答案：答案本身有单调性（答案越大，条件越容易满足），要求"满足条件的最小值"或"不超限制的最大值"。
   - 题目标志词："最小值最大"、"最大值最小"、"至少 k 个"。
   - 做法：设计一个 `check(x)` 判断"答案取 x 行不行"，再对答案范围二分。
   - 具体模板见文末代码 `binary_max_ans` / `binary_min_ans`，用法说明见【六】。
4. 浮点二分：求平方根、方程求根等（用 mid 逼近，靠精度或固定次数结束）。
5. 特殊的"半有序"序列：旋转数组、先升后降的山峰数组，可以把区间分成"一侧有序、一侧无序"来二分。

## 四、C++ 自带二分函数速查（`#include <algorithm>`）

以下函数都要求区间有序（递增），复杂度都是 O(logn)：

| 函数 | 返回值 | 作用 |
| --- | --- | --- |
| `binary_search(begin, end, x)` | bool | 只判断 x 是否存在，不返回位置 |
| `lower_bound(begin, end, x)` | 迭代器 | 返回第一个 >= x 的元素的位置 |
| `upper_bound(begin, end, x)` | 迭代器 | 返回第一个 > x 的元素的位置 |
| `equal_range(begin, end, x)` | pair | 同时得到前两个：first 是 `lower_bound`，second 是 `upper_bound` |

用 `lower_bound` 和 `upper_bound` 统计 x 出现的次数：

```cpp
ll cnt = upper_bound(a.begin(), a.end(), x)
       - lower_bound(a.begin(), a.end(), x);
```

两个迭代器相减的结果是 long long（ptrdiff_t），建议用 ll 接收，
不要用 int（原写法 int count = ... 在数据量大时有风险）。

## 五、写二分最容易犯的错（重点！）

1. `mid` 必须写在 while 循环里面！
   - left 和 right 每轮都在变，mid 也必须每轮重新算。
   - 反面写法：mid 算一次放在循环外 -> mid 永远是同一个值，要找的数不在那个位置上时就会漏判（明明存在却返回 -1）。
2. `(left + right)` 可能溢出：
   - 当 left 和 right 都很大时，相加可能爆 long long，更安全的写法：`mid = left + (right - left) / 2`。
3. 区间写法要统一：本模板用"闭区间 `[left, right]`"，while 条件是 `left <= right`，缩小范围用 `mid - 1` 和 `mid + 1`。
   - 另一种"左闭右开 `[left, right)`"写法条件不同，两种不要混用。
4. 空数组：`a.size() == 0` 时 `right = -1`，while 直接不进入，返回 -1，不会出错。

## 六、二分答案模板用法说明（对应文末的 `binary_max_ans` / `binary_min_ans`）

二分答案 = 把"答案"当成查找对象来二分。
关键在 `check(x)`：判断"答案取 x 行不行"，由题目自己实现。
只要 check 的结果有单调性（可行的是连续一段），就能二分出分界点。

两个版本按题目问法选择，不要用反：

1. 问"最大值"（答案越小越容易可行）-> 用 `binary_max_ans`
   - mid 必须向上取整：`mid = l + (r - l + 1) / 2`
   - 不加 1 会死循环：l=0、r=1 时 mid=0，若 check(0) 为真，执行 `l = mid = 0`，l 和 r 都不动，循环永远出不去。
2. 问"最小值"（答案越大越容易可行）-> 用 `binary_min_ans`
   - `mid = l + (r - l) / 2`，不用加 1。

经典题：砍树、分巧克力、跳石头、数列分段。

## 代码

```cpp
#include<iostream>
#include<vector>
// 如果要使用【四】中的 binary_search / lower_bound 等，需再加 #include<algorithm>
using namespace std;
using ll = long long;

// 迭代版本：时间复杂度 O(logn)，空间复杂度 O(1)，竞赛最常用
// 功能：在有序（递增）数组 a 中查找 num，找到返回下标，找不到返回 -1
// 查找区间写法：闭区间 [left, right]
ll mid_find1(const vector<ll>& a, ll num)
{
    ll left = 0, right = (ll)a.size() - 1;      // 初始搜索范围：整个数组

    while (left <= right)                       // 区间里还有元素就继续找
    {
        ll mid = left + (right - left) / 2;     // 关键！mid 每轮重算，且放在循环内；
                                                // 用 left + (right-left)/2 防止 left+right 溢出
        if (a[mid] > num) right = mid - 1;      // 目标在左半段：丢掉右半段
        else if (a[mid] < num) left = mid + 1;  // 目标在右半段：丢掉左半段
        else return mid;                        // 命中，返回下标
    }

    return -1;                                  // 区间空了（left > right）：数组里没有 num
}

// 递归版本：时间复杂度 O(logn)，空间复杂度 O(logn)（递归调用栈的深度）
// 功能同上：在 a 的闭区间 [left, right] 内查找 num
ll mid_find2(const vector<ll>& a, ll left, ll right, ll num)
{
    if (left > right) return -1;                // 递归出口：区间为空，没找到

    ll mid = left + (right - left) / 2;         // 取中间位置（防溢出写法）
    if (a[mid] == num) return mid;              // 命中，返回下标
    else if (a[mid] > num)                      // 目标在左半段：右边界缩到 mid - 1
        return mid_find2(a, left, mid - 1, num);
    else                                        // 目标在右半段：左边界扩到 mid + 1
        return mid_find2(a, mid + 1, right, num);
}

// ------------------------------------------------------------------
// 二分答案模板：题目问"满足条件的最大/最小答案"时使用
// 核心：把"答案"当成查找对象。check(x) 判断"答案取 x 行不行"，
//       可行区间是连续的一段，二分出可行与不可行的分界点即可。
// 示例题：a = {1,3,5,7,9}，k = 3，问"最大的 H，使 a 中 >= H 的数至少 k 个"
//        H=1 可行, H=3 可行, H=5 可行, H=7 不可行  -> 答案 H = 5
// ------------------------------------------------------------------

// check(x)：判断 x 是否可行，由题目自己实现
// 下面给出上面示例题的实现（demo_ 前缀是示例数据，实际写题换成题目的变量）
const vector<ll> demo_a = {1, 3, 5, 7, 9};
const ll demo_k = 3;
bool check(ll x)
{
    ll cnt = 0;
    for (ll v : demo_a) if (v >= x) cnt++;
    return cnt >= demo_k;                 // ">= x 的数至少有 k 个"就可行
}

// 用法一：求"满足条件的最大答案"
// 适用：答案越小越容易可行（可行区间在左边，如上面示例题）
// l、r 是答案可能的范围（闭区间），要保证 check(l) 为真（答案在区间内）
ll binary_max_ans(ll l, ll r)
{
    while (l < r)
    {
        ll mid = l + (r - l + 1) / 2;   // 关键！+1 向上取整，l 才可能前进；
                                        // 不加 1 会死循环：l=0,r=1 时 mid=0，
                                        // check(0) 为真 -> l=mid=0，区间纹丝不动
        if (check(mid)) l = mid;        // mid 可行：答案至少是 mid，去右半段找更大的
        else r = mid - 1;               // mid 不可行：答案比 mid 小，去左半段找
    }
    return l;                           // 此时 l == r，就是答案
}

// 用法二：求"满足条件的最小答案"
// 适用：答案越大越容易可行（可行区间在右边）
// 要保证 check(r) 为真（答案在区间内）
ll binary_min_ans(ll l, ll r)
{
    while (l < r)
    {
        ll mid = l + (r - l) / 2;       // 注意：这个版本不加 1
        if (check(mid)) r = mid;        // mid 可行：答案最大是 mid，去左半段找更小的
        else l = mid + 1;               // mid 不可行：答案比 mid 大，去右半段找
    }
    return l;                           // 此时 l == r，就是答案
}
```

# 差分模板（差分数组）

## 讲解思路

### 一、先看一个问题

有一个数组 a[1..n]，接下来有 q 个操作，每个操作是：
给区间 [l, r] 上的每个数都加上 val（叫"区间加"），
所有操作做完后，输出最终的数组。

如果每次都老老实实把 a[l] 到 a[r] 挨个加一遍，
一次操作最坏要 O(n) 时间，q 次就是 O(n*q)，数据一大就超时。

### 二、核心思想：用"相邻两个数的差"代替"每个数"

定义一个新数组 d（叫差分数组）：

```
d[1] = a[1]
d[i] = a[i] - a[i-1]     (i >= 2)
```

也就是 d 存的是 a 相邻两项的差。

反过来，a 可以由 d 拼回来（求和时中间项两两抵消）：

```
a[i] = d[1] + d[2] + ... + d[i]
```

举个例子：a = [1, 3, 6, 10]，则 d = [1, 2, 3, 4]，
算 a[3] = d[1]+d[2]+d[3] = 1+2+3 = 6，正好等于原值。

### 三、区间加为什么只改两个位置？

假如给 d[l] 加 val，其他不动：
因为 a[i] = d[1]+...+d[i]，所以凡是 i >= l 的 a[i] 全都会 +val，
相当于 [l, n] 整个尾巴都被加了 val——加的范围"超了"。

那就再给 d[r+1] 减 val：
凡是 i >= r+1 的 a[i] 又会 -val，正好把超出的部分抵消掉。
一加一减配合，最终效果：只有 [l, r] 被加了 val，其余不变。

所以一次区间加只需两行：

```cpp
d[l]     += val;
d[r + 1] -= val;    // 注意 r 可能等于 n，d 数组要多开一位（n+2）
```

### 四、完整流程（三步走）

1. 由原数组建差分数组 d
2. 用"改两个位置"的方法处理全部 q 个操作（每次 O(1)）
3. 对 d 求一遍前缀和，还原出最终数组

### 五、二维差分（扩展）

二维差分数组定义为：

```
d[i][j] = a[i][j] - a[i-1][j] - a[i][j-1] + a[i-1][j-1]
```

反过来，a[i][j] 就是 d 的二维前缀和：

```
a[i][j] = a[i-1][j] + a[i][j-1] - a[i-1][j-1] + d[i][j]
```

对矩形 (x1,y1) 到 (x2,y2) 整体加 val，只需改四个角：

```cpp
d[x1][y1]       += val;
d[x1][y2+1]     -= val;
d[x2+1][y1]     -= val;
d[x2+1][y2+1]   += val;
```

直觉理解（想象在平面上"贴标签"）：
在 (x1,y1) 贴一个 +val 标签，它让"右下方向"所有点的前缀和都 +val，
也就是整个右下大矩形都被加了；
在 (x1,y2+1) 和 (x2+1,y1) 各贴一个 -val 标签，
把大矩形右边和下边多出的部分减回去；
右下角 (x2+1,y2+1) 被两个 -val 标签各减一次（共减两次，多减了），
所以再贴一个 +val 标签补回来。
四个标签共同作用，最终只有原矩形内部被加了 val。

## 时间复杂度

- 建差分数组：O(n)（一维）或 O(n*m)（二维）
- 每次区间/矩形加操作：O(1)
- 最后前缀和还原：O(n) 或 O(n*m)
- 总共：O(n + q)（q 为操作个数），暴力直接改是 O(n*q)
- 额外空间：O(n)

## 适用题型

1. 批量"区间整体加同一个数"，且修改全部在查询之前（先改完再问）：
   例如借教室、给气球染色、每次给 [l,r] 加 v 最后问某个位置的值
2. 二维"子矩阵整体加同一个数"，最后统一输出整个矩阵
3. 差分 + 前缀和：求修改后的区间和 / 矩阵和
4. 差分 + 贪心：某些按大小安排操作顺序的题（如"最少操作使数组单调不降"）

判断标准：只要修改是"整体加同一个值"且可以离线（先全部改完再查询），
首选差分。注意：

- 修改和查询交替出现（在线），或要做"区间赋值 / 取最大最小"等，
  差分不适用，要用树状数组或线段树。
- 差分只能整体加同一个值；每个位置加的值不同，就退化回暴力。

## 完整代码

```cpp
#include <iostream>
#include <vector>
using namespace std;
using ll = long long;

int main()
{
    // ==================== 一维差分 ====================
    int n;
    cin >> n;
    vector<ll> a(n + 2), d(n + 2);  // 多开一位：区间加要访问 d[r+1]，r = n 时是 n+1

    // 第 1 步：读入并建差分数组
    // d[i] = a[i] - a[i-1]（a[0] = 0，所以 i = 1 时这条公式也成立）
    for (int i = 1; i <= n; i++)
    {
        cin >> a[i];
        d[i] = a[i] - a[i - 1];
    }

    // 第 2 步：处理 q 次区间加，每次 O(1)
    int q;
    cin >> q;
    while (q--)
    {
        int l, r;
        ll val;
        cin >> l >> r >> val;
        d[l] += val;       // [l, n] 全 +val
        d[r + 1] -= val;   // 从 r+1 起抵消，最终只有 [l, r] 被 +val
    }

    // 第 3 步：对 d 求前缀和，还原最终数组
    for (int i = 1; i <= n; i++)
    {
        a[i] = a[i - 1] + d[i];   // a[i] = d[1] + d[2] + ... + d[i]
        cout << a[i] << " ";
    }
    cout << endl;

    // ==================== 二维差分 ====================
    // 数组声明（同样多开一位，防止 x2+1 / y2+1 越界）：
    // vector<vector<ll>> a(n + 2, vector<ll>(m + 2)),
    //                    d(n + 2, vector<ll>(m + 2));
    //
    // 建二维差分数组：
    // d[i][j] = a[i][j] - a[i-1][j] - a[i][j-1] + a[i-1][j-1];
    //（越界的 a[0][j]、a[i][0] 均视为 0）
    // 另一种等价建法：把每个 a[i][j] 当成对 1x1 的矩形加 a[i][j]，
    // 直接套用下面的四角公式逐个"插入"。
    //
    // 矩形 (x1,y1) ~ (x2,y2) 整体 +val，改四个角：
    // d[x1][y1]       += val;
    // d[x1][y2+1]     -= val;
    // d[x2+1][y1]     -= val;
    // d[x2+1][y2+1]   += val;
    //
    // 最后对 d 就地求二维前缀和，求完 d[i][j] 就是最终答案：
    // for (int i = 1; i <= n; i++)
    //     for (int j = 1; j <= m; j++)
    //         d[i][j] += d[i-1][j] + d[i][j-1] - d[i-1][j-1];

    return 0;
}
```

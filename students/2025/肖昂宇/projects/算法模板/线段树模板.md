# 线段树（Segment Tree）模板

## 一、线段树是干什么的？

假设有一个数组 `a[0..n-1]`，需要反复进行两种操作：

- **操作1（单点修改）**：把 `a[i]` 改成新值
- **操作2（区间查询）**：求 `a[l] + a[l+1] + ... + a[r]`（区间和；换成最大/最小值也同理）

两种操作会混合着来很多次。

直接想朴素做法，会发现"鱼与熊掌不可兼得"：

| 做法 | 修改 | 查询 | 问题 |
| --- | --- | --- | --- |
| 暴力 | O(1) 很快 | 每次扫描区间 O(n) | 查询一多就超时 |
| 前缀和 | 改一个 a[i] 后面全部跟着变，O(n) | O(1) 很快 | 修改一多就超时 |

**线段树的价值：让修改和查询都变成 O(log n)，两边都很快。**

## 二、线段树长什么样？

线段树是一棵二叉树，每个节点负责管着数组的一段区间 `[l, r]`：

- 根节点（编号 1）管整个数组 `[0, n-1]`；
- 每个节点把自己管的区间从正中间一分为二，左半给左儿子，右半给右儿子；
- 一直分下去，直到区间里只剩一个元素，那就是叶子节点。

以 n = 8 为例（数组下标 0..7）：

```text
                    [0,7] 编号1
                 /          \
            [0,3] 编号2     [4,7] 编号3
           /      \         /      \
       [0,1]      [2,3]   [4,5]    [6,7]
       /  \       /  \    /  \     /  \
     [0]  [1]   [2] [3]  [4] [5]  [6] [7]   ← 叶子 = 单个元素
```

## 三、节点编号规律（为什么能用数组存）

这棵树是"完全二叉树"（每层从左到右连续排满），所以可以不用指针，直接按下面的编号规律塞进一个数组：

- 根节点编号 = 1；
- 编号为 i 的节点：左儿子 = `2 * i`，右儿子 = `2 * i + 1`。

于是只需要一个数组 `tree[]`，`tree[i]` 就存"编号 i 的节点所管区间的和"。

**为什么开 4 * n 倍空间？**
最坏情况下（n 不是 2 的整次幂时）整棵树的节点数不会超过 4n，所以数组开 `4 * n` 最保险，永远不越界。空间稍多一点没关系。

## 四、三个核心操作的思想

**1. 建树 build**：递归地把区间一分为二，先建好左右儿子，再用儿子的值算出父亲的值（自底向上合并）：

```text
tree[父亲] = tree[左儿子] + tree[右儿子]
```

**2. 区间查询 query(node, l, r, ql, qr)**：在树上找出 `[ql, qr]` 覆盖了哪些节点，分三种情况：

- **情况1 完全无关**：当前区间与 `[ql, qr]` 一点不重叠 → 返回 0（0 加不加都不影响和）。
- **情况2 完全覆盖**：当前区间整个都在 `[ql, qr]` 里面 → 直接返回 `tree[node]`，不再往下找。
- **情况3 部分重叠**：左右两半都递归去问，把结果加起来。

快的秘诀就在情况2：一整个节点对应一大段区间，直接"整段拿走"，不需要一个一个元素去访问。每层最多只有 2 个节点需要继续往下走，所以总共访问 O(log n) 个节点。

**3. 单点修改 update**：一路往下找到叶子（只有叶子存着具体元素），改完值之后原路返回，沿路的每个父亲都重新合并一次——因为儿子的值变了，父亲的和可能也变了。

**4.（进阶）区间修改 + 懒标记**：
如果要给整个区间每个元素都加上/改成某个值，一个个单点修改太慢。
懒标记思路：修改时遇到"完全覆盖"的节点就停下来，只改这个节点并打上一个标记（表示"我的儿子们还没收到这次修改"）；等以后真正要访问儿子时，再把标记下推给儿子（push_down）。详见代码后半部分。

## 五、时间复杂度

| 操作 | 复杂度 | 说明 |
| --- | --- | --- |
| 建树 | O(n) | 每个节点恰好被访问一次 |
| 单点修改 | O(log n) | 只走一条从根到叶子的路径，路径长度 = 树高 ≈ log n |
| 区间查询 | O(log n) | 理由见上面"情况2"的说明 |
| 空间 | O(n) | 数组实际开 4 * n |

## 六、适用题型

1. 维护"可合并的信息" + 单点/区间修改：区间和、最大值、最小值、gcd、异或和……只要两个小区间的信息能快速拼成大区间的信息，就能套线段树。
2. 静态区间最值（不修改）用 ST 表查询 O(1) 更快；线段树的优势是支持修改。
3. 经典题目：
   - 洛谷 P3372【模板】线段树 1 —— 区间加 + 区间求和（用下面的懒标记版本）
   - 洛谷 P3373【模板】线段树 2 —— 区间乘 + 区间加（进阶）
   - 洛谷 P1816 忠诚 —— 静态区间最小值（把求和换成 min 即可）
   - HDU 1166 敌兵布阵 —— 单点修改 + 区间求和（正是本模板的上半部分）
4. 进阶应用：求逆序对、扫描线（用线段树维护值域）。
5. 若只是"单点修改 + 区间求和"，树状数组代码更短；但线段树更通用，能处理区间修改、最值等树状数组不好做的需求。

## 七、常见坑（新手必看）

1. 求最小值时，query 的"完全无关"**不能返回 0**！0 是很小的数，会把 min 结果算错；要返回一个极大值（如 1e18）。
2. 本模板数组下标从 0 开始：调用时写 `build(1, 0, n-1, a)`；若你的题目习惯下标从 1 开始，把调用时的 0 都改成 1 即可（函数内部不用动）。
3. 用了懒标记（区间修改）后，查询必须用带 push_down 的查询函数，不能再用没有懒标记的普通 query，否则会漏掉"还没下推的修改"；同理单点修改也要统一走 update_range（l == r 就是单点）。
4. 若 l、r 可能超过 2e9，`(l + r) / 2` 会溢出，应写成 `l + (r - l) / 2`。

## 代码实现

### 头文件与全局变量

```cpp
#include<iostream>
#include<vector>
#include<algorithm>
using namespace std;
using ll = long long;

const ll N = 100;       // 数组最大长度，按题目改
ll tree[4 * N];         // 线段树节点数组。为什么开 4 倍见开头【三】
```

### 建树

```cpp
// ============ 建树 ============
// node：当前节点编号；[l, r]：这个节点负责的区间
// 调用：build(1, 0, n - 1, a)
void build(ll node, ll l, ll r, const vector<ll>& a)
{
	if (l == r)  // 叶子节点：区间里只有一个元素，直接取原数组的值
	{
		tree[node] = a[l];
		return;
	}

	ll mid = (l + r) / 2;
	build(2 * node, l, mid, a);            // 递归建左儿子（左半区间 [l, mid]）
	build(2 * node + 1, mid + 1, r, a);    // 递归建右儿子（右半区间 [mid+1, r]）

	// 儿子都建好了，合并出父亲的值（自底向上）
	// 区间和：
	tree[node] = tree[2 * node] + tree[2 * node + 1];
	// 最小值（改成求最小值时用这一行；注意 query 里的"完全无关"返回值也要跟着改，见 query 注释）：
	//tree[node] = min(tree[2 * node], tree[2 * node + 1]);
}
```

### 区间查询

```cpp
// ============ 区间查询 ============
// 询问 [ql, qr] 的和；当前在节点 node，负责区间 [l, r]
// 调用：query(1, 0, n - 1, ql, qr)
ll query(ll node, ll l, ll r, ll ql, ll qr)
{
	// 情况1：当前区间与 [ql, qr] 完全不重叠 → 返回一个"不影响结果"的值
	// 0 是加法的"不影响"值，只对求和成立；
	// 若求最小值，这里必须返回极大值（如 1e18），否则 0 会把 min 算错！
	if (qr < l || ql > r) return 0;

	// 情况2：当前区间整个被 [ql, qr] 包含 → 整段拿走，不用再往下找
	if (ql <= l && qr >= r) return tree[node];

	// 情况3：部分重叠 → 左右两半分别询问，再把结果合并
	ll mid = (l + r) / 2;
	return query(2 * node, l, mid, ql, qr) + query(2 * node + 1, mid + 1, r, ql, qr);
}
```

### 单点修改

```cpp
// ============ 单点修改 ============
// 把下标 idx 的值改成 val；当前在节点 node，负责区间 [l, r]
// 调用：update(1, 0, n - 1, idx, val)
void update(ll node, ll l, ll r, ll idx, ll val)
{
	if (l == r)  // 走到叶子：这个叶子存的就是 a[idx]
	{
		tree[node] = val;
		return;
	}

	ll mid = (l + r) / 2;
	// idx 落在哪一半，就去改哪一半；另一半完全不用动
	if (idx <= mid) update(2 * node, l, mid, idx, val);
	else update(2 * node + 1, mid + 1, r, idx, val);

	// 儿子的值可能变了，沿路回来的每个父亲都要重新合并
	// 区间和：
	tree[node] = tree[2 * node] + tree[2 * node + 1];
	// 最小值：
	//tree[node] = min(tree[2 * node], tree[2 * node + 1]);
}
```

### 进阶：区间修改（懒标记）

```cpp
// ============ 进阶：区间修改（懒标记）============
// 上面的单点修改每次都要走到叶子，给整个区间每个元素都改一遍就会太慢。
// 懒标记思路：修改时遇到"完全覆盖"的节点就停，只改这个节点并打标记，
// 等以后真正要访问它的儿子时，才把标记下推给儿子（push_down）。
// 这样区间修改也是 O(log n)。
//
// 注意：以下三个函数要一起使用；一旦用了区间修改，
// 查询也要用带 push_down 的 query_range，不能用上面的普通 query！
ll tag[4 * N];   // 懒标记：tag[node] = "node 还没传给儿子的待加值"（全局数组自动初始化为 0）

// 把当前节点的懒标记下推给左右儿子（只下推一层）
void push_down(ll node, ll l, ll r)
{
	if (tag[node] == 0) return;   // 没有标记，不需要下推
	ll mid = (l + r) / 2;

	// 左儿子管 [l, mid]，共 mid - l + 1 个元素，每个都要 + tag[node]
	tag[2 * node] += tag[node];
	tree[2 * node] += tag[node] * (mid - l + 1);

	// 右儿子管 [mid+1, r]，共 r - mid 个元素
	tag[2 * node + 1] += tag[node];
	tree[2 * node + 1] += tag[node] * (r - mid);

	tag[node] = 0;   // 标记已经传给儿子，清空
}

// 区间修改：给 [ql, qr] 每个元素都 + val
// 调用：update_range(1, 0, n - 1, ql, qr, val)
void update_range(ll node, ll l, ll r, ll ql, ll qr, ll val)
{
	if (qr < l || ql > r) return;   // 完全无关：不管

	if (ql <= l && qr >= r)         // 完全覆盖：本节点一次性改完，打上标记就返回
	{
		tree[node] += val * (r - l + 1);  // 每个元素 + val，共 (r - l + 1) 个
		tag[node] += val;                 // 记下"儿子们还欠这次修改"
		return;
	}

	// 部分重叠：先下推旧标记，再递归改左右儿子，最后合并
	push_down(node, l, r);
	ll mid = (l + r) / 2;
	update_range(2 * node, l, mid, ql, qr, val);
	update_range(2 * node + 1, mid + 1, r, ql, qr, val);
	tree[node] = tree[2 * node] + tree[2 * node + 1];
}

// 带懒标记的区间查询：与普通 query 的唯一区别是递归访问儿子前先 push_down
// 调用：query_range(1, 0, n - 1, ql, qr)
ll query_range(ll node, ll l, ll r, ll ql, ll qr)
{
	if (qr < l || ql > r) return 0;
	if (ql <= l && qr >= r) return tree[node];

	push_down(node, l, r);   // 访问儿子前必须先下推，否则儿子存的是旧信息
	ll mid = (l + r) / 2;
	return query_range(2 * node, l, mid, ql, qr) + query_range(2 * node + 1, mid + 1, r, ql, qr);
}
```

### 使用示例

**区间加 + 区间求和（对应洛谷 P3372）：**

```cpp
int main()
{
	ll n, m;               // n 个元素，m 次操作
	cin >> n >> m;
	vector<ll> a(n);
	for (int i = 0; i < n; i++) cin >> a[i];

	build(1, 0, n - 1, a);

	while (m--)
	{
		int op;
		cin >> op;
		if (op == 1)                     // 区间修改：[l, r] 每个元素 + val
		{
			ll l, r, val;
			cin >> l >> r >> val;
			update_range(1, 0, n - 1, l, r, val);
		}
		else                             // 区间查询：[l, r] 的和
		{
			ll l, r;
			cin >> l >> r;
			cout << query_range(1, 0, n - 1, l, r) << '\n';
		}
	}
	return 0;
}
```

**不用懒标记时的调用（对应 HDU 1166）：**

```cpp
build(1, 0, n - 1, a);
update(1, 0, n - 1, idx, val);   // 单点修改
query(1, 0, n - 1, l, r);        // 区间查询
```

# 滚动哈希（字符串哈希）模板 —— 双哈希版

## 一、讲解思路（写给 0 基础）

### 1. 哈希是干什么的？

给每个字符串算出一个"编号"（哈希值），两个字符串编号相同就认为它们相同。
这样比较两个很长的字符串时，不用逐字符比较，只需比较两个编号，O(1) 完成。

### 2. 怎么把字符串变成编号？—— 把字符串看成 B 进制数

把字符串 `s[0..n-1]` 看成一个 B 进制数，每个字符的 ASCII 码当作一位"数字"。
例如 `s = "abc"` 在 B 进制下的值就是：

```
a * B^2 + b * B^1 + c * B^0
```

这个值就是哈希值。B 取一个质数（如 131、13331），
不同的字符串几乎一定会得到不同的值。

### 3. 为什么要取模？

字符串一长，这个 B 进制数会大到超出 `long long` 的范围。
所以每算一步都对一个大质数 MOD 取模，把值压回 `long long` 范围内。

### 4. 为什么要用"双哈希"？

取模后可能出现哈希冲突：两个不同的字符串碰巧得到同一个编号。
单哈希出错的概率已经很小，但出题人可以专门构造数据来"卡"你。
于是用两套不同的 base 和 MOD 各算一遍，得到一对编号 `(h1, h2)`，
两个编号都相等才认为字符串相等，冲突概率小到几乎为 0，很难被卡。

### 5. 核心技巧：前缀哈希（查任意子串的哈希只要 O(1)）

记 `h[i]` = 前 i 个字符组成的串的哈希值（`h[0] = 0`），递推：

```
h[i+1] = (h[i] * B + s[i]) % MOD
```

含义：在老串后面"添一位"，相当于老数乘 B（整体左移一位）再加新数字。

同时预处理 `p[i] = B^i % MOD`（B 的 i 次方），后面要用。

求子串 `s[l..r]`（l、r 从 0 数，闭区间）的哈希：

```
hash(l, r) = (h[r+1] - h[l] * p[r-l+1]) % MOD
```

怎么来的？`h[r+1]` 是前 r+1 个字符的值，`h[l]` 是前 l 个字符的值。
把 `h[l]` 乘上 `B^(r-l+1)`（把前 l 位"垫高"到和 `h[r+1]` 相同的高度），
相减后前 l 个字符的贡献就消掉了，剩下的正好是 `s[l..r]` 的值。
类比十进制：`12345 - 12 * 10^3 = 345`，取到的就是后三位。

### 6. 为什么叫"滚动"哈希？

从子串 `s[l..r]` 移到相邻的 `s[l+1..r+1]`，只需去掉一个字符、加上一个字符，
可以 O(1) 递推出新哈希。本模板用前缀哈希公式实现，每次查询同样是 O(1)。

## 二、时间复杂度

- 预处理（构造函数中算前缀哈希）：O(N)，N 为字符串长度
- 单次查询子串哈希：O(1)
- 总复杂度：O(N + Q)，Q 为查询次数

## 三、适用题型

1. 字符串匹配 / 求子串出现位置（KMP 能做的题基本都能做，而且更好写）
2. 最长回文子串（二分长度 + 哈希 O(1) 判断左右两半是否相等）
3. 寻找最长重复子串（二分长度 + 哈希判断两段是否相等）
4. 多次快速比较任意两个子串是否相等（判断循环节、区间内容相同等）
5. 与二分答案结合的各种"子串相等"类问题

凡是"需要多次快速判断字符串片段是否相等"的题，都可以考虑滚动哈希。

## 四、使用注意

- `get_hash(l, r)` 中 l、r 从 0 开始，取闭区间 `[l, r]`。
- s 中字符直接用 ASCII 码作"数字"，常规题目（小写字母、数字等）够用。

## 五、代码

```cpp
#include <iostream>
#include <vector>
#include <string>
using namespace std;
using ll = long long;

// 两套底数（进制）和模数：双哈希，防止单哈希被构造数据卡掉
const ll base1 = 131, base2 = 13331;      // B：把字符串看成 B 进制数
const ll MOD1 = 1e9 + 7, MOD2 = 1e9 + 9;  // 大质数模数，防止数值溢出 long long

struct StringHash
{
	vector<ll> h1, p1;  // h1[i] = 前 i 个字符的前缀哈希（mod MOD1），p1[i] = base1^i % MOD1
	vector<ll> h2, p2;  // 第二套哈希（mod MOD2），作用同上
	ll n;               // 字符串长度

	StringHash(const string& s)
	{
		n = s.size();

		// 多开 1 位：h[0] = 0（空串哈希为 0），p[0] = 1（B^0 = 1）
		h1.resize(n + 1, 0); p1.resize(n + 1, 1);
		h2.resize(n + 1, 0); p2.resize(n + 1, 1);

		// 递推求前缀哈希：h[i+1] = h[i] * B + s[i]（B 进制数末尾添一位）
		// 同时递推 p[i+1] = p[i] * B（即 B^(i+1)），供 get_hash 使用
		for (ll i = 0; i < n; i++)
		{
			h1[i + 1] = (h1[i] * base1 + s[i]) % MOD1;
			p1[i + 1] = (p1[i] * base1) % MOD1;

			h2[i + 1] = (h2[i] * base2 + s[i]) % MOD2;
			p2[i + 1] = (p2[i] * base2) % MOD2;
		}
	}

	// 返回子串 s[l..r]（闭区间，下标从 0 开始）的双哈希值
	pair<ll, ll> get_hash(ll l, ll r)
	{
		// 核心公式：hash(l, r) = h[r+1] - h[l] * B^(r-l+1)
		// 把前缀 h[l] "垫高" r-l+1 位再减，消掉前 l 个字符的贡献
		// (+MOD) % MOD 是为了把可能为负的差变成正的取模结果
		ll hash1 = ((h1[r + 1] - h1[l] * p1[r - l + 1]) % MOD1 + MOD1) % MOD1;
		ll hash2 = ((h2[r + 1] - h2[l] * p2[r - l + 1]) % MOD2 + MOD2) % MOD2;
		return { hash1, hash2 };  // 两个值都相等才算字符串相等
	}
};

int main()
{
	string s = "helloworld";
	StringHash hasher(s);

	auto h_ello = hasher.get_hash(1, 4);  // s[1..4] = "ello"

	cout << "Hash of 'ello':" << h_ello.first << "," << h_ello.second << endl;

	// 比较两个子串是否相等的典型用法：
	// if (hasher.get_hash(l1, r1) == hasher.get_hash(l2, r2)) 两段相等

	return 0;
}
```

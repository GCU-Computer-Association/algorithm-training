# 字典树（Trie，也叫前缀树）模板

> 来源：`D:\VS\c++模板\字典树模板.cpp`

## 一、它是个什么东西？

字典树是一棵"会共用开头"的树。普通数组存单词是各存各的，
而字典树把开头相同的部分合并成一条路，只在不一样的地方分叉。
例如插入 cat 和 car：

```
        (根)
          |
          c
          |
          a
         / \
        t   r
      (结束)(结束)
```

每个字母是"树的一条边"，根节点本身不存字符，只是一个空起点；
顺着边走完一个单词，就在最后一个节点打个"结束标记"。

## 二、每个节点存什么？

1. `children[26]`：26 个格子对应 26 个小写字母 a~z。
   - 字符 c 对应的格子是 `idx = c - 'a'`（'a'->0，'b'->1，...）。
   - 格子里存 0 表示"这个方向没有儿子"；
   - 格子里存 k 表示"这个方向的儿子是第 k 号节点"。
2. `isEnd`（结束标记）：走到这个节点时，是否刚好构成一个完整单词。
   这是 `search` 和 `startsWith` 最本质的区别：
   - `search`：路能走通还不够，最后节点的 isEnd 必须是 true（必须是完整单词）；
   - `startsWith`：只要路能走通就算数，最后节点不用管 isEnd（只是前缀）。

## 三、为什么用 vector 存节点、用下标代替指针？

1. 所有节点连续放在数组里，访问是 O(1) 的数组寻址，比指针跳转快且好写；
2. 不用 new/delete，不会漏释放内存；
3. 有一个重要约定：0 号节点永远是根（构造函数里第一个放进 pool 的），
   真正的单词节点从 1 号开始编号。所以 `children[idx] == 0`
   可以放心地兼任"这个方向没有儿子"的判断，不会和任何真节点撞号。

## 四、三个操作在干什么？

1. `insert`（插入单词）：从根出发，逐字符往下走；
   - 发现某方向没有儿子（== 0）就现场新建一个节点：
     - 新节点的编号 = 当时的 `pool.size()`（编号从 0 开始，size 正好是下一个可用编号）；
     - 然后 `emplace_back` 把它放进 pool；
   - 走到最后一个字符后，给当前节点标记 `isEnd = true`。
2. `search`（查找完整单词）：和插入一样往下走，但半路任何一步走不通
   就直接返回 false；能走完还要检查最后节点的 isEnd。
3. `startsWith`（判断前缀）：和 search 几乎一样，只是最后不用检查 isEnd。

> 注意：本模板默认只支持 26 个小写字母；如果题目出现大写字母或数字，
> 需要把 children 的数组大小改成对应字符集的个数。

## 时间复杂度

设单个字符串长度为 L，一共有 n 个字符串：

- 单次 insert / search / startsWith 都是 O(L)：从头到尾只把字符走一遍；
- 把 n 个字符串全部插入：O(n * L)；
- 空间复杂度：最坏 O(n * L)（所有字符串毫无共同前缀时，每个字符都要一个
  新节点）；共同前缀越多，省的空间越多。

## 适用题型

1. **前缀查询与统计**：某前缀出现了多少次、有多少单词以 xx 开头。
   （模板可在节点里加一个 cnt 计数：每次插入路过该节点就 cnt++）
2. **字符串搜索与匹配**：单词是否出现过、单词搜索游戏
   （Trie + DFS/BFS 回溯剪枝）。
3. **异或最大值问题**：把数字按二进制位建成 0/1 字典树，
   贪心地走相反位，即可求出最大异或值。
4. **字典序处理与去重**：按字典序输出所有字符串、判断重复单词、自动补全。

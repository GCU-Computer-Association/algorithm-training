# 状态压缩 DP 模板

> 来源：`D:\VS\c++模板\状态压缩模板.cpp`

## 一、什么是"状态压缩"

把"某些东西选了 / 没选"记成一个二进制数。
例如有 4 个城市，编号 0~3，用 4 个二进制位表示"去过了哪些城市"：

```
1001 = 9  → 表示去过了 0 号和 3 号城市
（从右往左数，第 i 位代表 i 号城市：1 = 去过，0 = 没去过）
```

这样一个普通整数就把一整组信息"压缩"了。

为什么可行？因为 N 很小时（一般 N <= 20），状态总数只有 2^N 个
（N=20 也就 100 万出头），电脑可以全部枚举一遍。
所以状态压缩 DP 只用于 N 很小的题目。

## 二、核心：旅行商问题（TSP）

**问题**：N 个城市，两两距离为 a[i][j]。从 0 号出发，
每个城市恰好去一次，最后回到 0 号，求最短总路程。

### dp 的含义

`dp[mask][i]`：已经去过的城市集合是 mask，最后到达（当前正站在）的城市是 i，
此时走过的最短路程。

### 初始化

- `dp[1][0] = 0`（1 = 1<<0，表示"只去过 0 号城市"，路程当然是 0）
- 其余全部设成无穷大 INF，表示这个状态还没走到过。

### 转移（如何由已知状态推出新状态）

站在 i 号城市，挑一个没去过的城市 j 走过去：

```
新集合   next_mask = mask | (1 << j)   （把 j 加入集合）
新路程   dp[next_mask][j]
         = min(原来的值, dp[mask][i] + a[i][j])
```

> 注意：必须加上边权 a[i][j]！漏掉它答案就会变成
> "直接回家的最短距离"，这是本模板最容易错的一步。

### 最终答案

所有城市都去过 = `full_mask = (1<<N) - 1`（N 个二进制位全是 1）
最后站在 i，还要走回起点 0：

```
ans = min( dp[full_mask][i] + a[i][0] )，i 从 0 到 N-1
```

若 ans 仍是 INF，说明不存在合法回路，返回 -1。

## 三、模板 2：枚举 mask 的所有子集

```cpp
for (sub = mask; sub > 0; sub = (sub - 1) & mask)
```

- sub 从 mask 本身开始，按数值从大到小枚举 mask 的每一个非空子集。
- 原理：(sub - 1) 把 sub 最低位的 1 变 0、比它低的位全变 1；
  再 & mask 清掉不属于 mask 的位，结果仍是 mask 的子集。
- 注意：不含空集；想包含空集需单独处理（或写成 do-while）。
- 复杂度：枚举所有 mask 的所有子集，总共 O(3^N)。

## 时间复杂度

1. **旅行商问题（本模板）**：状态数 O(2^N)，每个状态枚举两个城市，
   总复杂度 O(N^2 * 2^N)，空间 O(N * 2^N)。
2. **枚举子集**：O(3^N)。

一般 N 不超过 20（再大 2^N 就存不下了）。

## 适用题型

### 1. 旅行商问题

经过每个点恰好一次的最短回路，如送货路径规划。

### 2. 棋盘/网格放置问题

- 在 N*M 的网格中放置物品（车、国王、多米诺骨牌等）
- 存在相邻冲突限制（不能放在相邻格子、某些格子是障碍物）
- 通常 N*M 中有一维非常小（<=12），另一维可以较大

**解题套路**：按行 DP。`dp[i][mask]` 表示处理到第 i 行，
且第 i 行的放置状态为 mask 时的最大收益/方案数。
转移时先检查 mask 自身是否合法（如 `(mask & (mask<<1)) == 0`
表示行内没有相邻放置），再检查与上一行 prev_mask 是否冲突
（通常用 `(mask & prev_mask) == 0` 判断）。

**典型例题**：互不侵犯（国王）、炮兵阵地、蒙德里安的梦想（铺砖）

### 3. 集合划分与任务分配

- 将 N 个物品/任务分配给 K 个人/组
- 每个人/组有容量限制或特定收益规则
- N <= 15~20

**解题套路**：`dp[mask]` 表示已分配 mask 集合的任务时的
最小代价/最大收益。转移时枚举下一个要分配的子集。

### 4. 图论中的特殊连通性/路径问题

- 判断图中是否存在包含特定节点集合的连通子图
- 求经过特定颜色/类型节点的最短路径

**解题套路**：结合 BFS 或 Dijkstra，把 mask 作为状态的一部分
放入队列/优先队列，即 `dist[mask][u]`。

**典型例题**：斯坦纳树

## 模板代码

```cpp
#include<bits/stdc++.h>
using namespace std;
using ll = long long;

const ll INF = 1e18;

//模板1：旅行商问题（TSP）
//a[i][j] 表示城市 i 到 j 的距离，从 0 号出发最后回到 0 号
ll solve(vector<vector<ll>>& a)
{
	ll n = a.size();                       // 城市个数
	// dp[mask][i]：去过的城市集合为 mask、最后站在 i 号城市的最短路程
	vector<vector<ll>> dp(1 << n, vector<ll>(n, INF));
	dp[1][0] = 0;                          // 初始：只去过 0 号城市（1 = 1<<0），路程为 0

	// 按 mask 从小到大枚举，保证转移用到的小状态已经算好
	for (ll mask = 1; mask < (1 << n); mask++)
	{
		// 枚举当前站在哪个城市 i（必须已去过 i，且该状态可达）
		for (ll i = 0; i < n; i++)
		{
			if (!(mask & (1 << i)) || dp[mask][i] == INF) continue;

			// 枚举下一个要去的城市 j（必须还没去过 j）
			for (ll j = 0; j < n; j++)
			{
				if (mask & (1 << j)) continue;
				ll next_mask = mask | (1 << j);   // 把 j 加入集合
				dp[next_mask][j] = min(dp[next_mask][j],
					dp[mask][i] + a[i][j]);       // 关键：必须加上边权 a[i][j]
			}
		}
	}

	ll ans = INF;
	ll full_mask = (1 << n) - 1;   // n 位全是 1，表示所有城市都去过
	// 最后站在 i，还要走回起点 0，取最小值
	for (ll i = 0; i < n; i++) ans = min(ans, dp[full_mask][i] + a[i][0]);

	return ans == INF ? -1 : ans;  // 无解（图不连通）返回 -1
}

//模板2：枚举 mask 的所有非空子集（可独立使用，常用于集合划分 DP 的转移）
//复杂度 O(3^n)，需要空集时单独处理
void enumerate_subsets(ll mask)
{
	for (ll sub = mask; sub > 0; sub = (sub - 1) & mask)
	{
		// sub 就是 mask 的一个子集，按数值从大到小枚举
		// 原理：(sub - 1) 把 sub 最低位的 1 变 0、比它低的位全变 1
		//       再 & mask 清掉不属于 mask 的位，结果仍是 mask 的子集
	}
}

int main()
{
	//示例：4 个城市的距离矩阵，正确答案为 80（0->1->3->2->0）
	vector<vector<ll>> dist = {
		{0,10,15,20},
		{10,0,35,25},
		{15,35,0,30},
		{20,25,30,0}
	};

	cout << "最短路径长度：" << solve(dist) << endl;

	return 0;
}
```

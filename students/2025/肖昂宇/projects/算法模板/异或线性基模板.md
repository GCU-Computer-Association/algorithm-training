# 异或线性基模板

线性基：从一堆整数中提炼出少量基向量（个数 <= 位数），使得"用基做异或"能得到与原集合完全相同的所有异或结果。把 2^n 种枚举压缩到几十个数上的简单运算。

## 一、在解决什么问题？

给你一堆整数，允许随便挑其中任意几个做异或（每个数最多用一次），所有可能得到的异或结果最多有 2^n 种。

线性基的作用：从这一堆数里"提炼"出一小部分（最多不超过位数，如 64 位整数最多 64 个），使得"用提炼出的数做异或"和"用原来所有数做异或"能得到的结果完全一样。

于是原来要 2^n 种枚举的问题，就变成了在几十个数上做简单运算。

## 二、直观理解

把每个数看成二进制下的 01 向量，每一位是一个"维度"。线性基 = 这个向量组的一个"压缩版"：

- 压缩后最多只有"位数"这么多个数（每个数占一个不同的最高位）；
- 每个基向量的最高位互不相同；
- 原来所有数能异或出的所有值，用基里的数异或也都能得到，一个不多一个不少。

## 三、insert（插入）的思路

把 x 从最高位往最低位看：

1. 第 i 位是 0：跳过，看更低的位；
2. 第 i 位是 1、且这一位还没有基：x 直接作为第 i 位的基存下来，结束；
3. 第 i 位是 1、且这一位已有基 basis[i]：x ^= basis[i]（异或消掉这一位），再继续处理更低的位。

这样保证：存进 basis[i] 的数，第 i 位一定是它的最高位（比 i 高的位全是 0）。

## 四、get_max（求最大值）的思路

从最高位往最低位贪心，res 从 0 开始：

- 第 i 位只有 basis[i] 能影响：更低的基最高位低于 i 影响不到这一位；比 i 高的位早已处理完定死了，而 basis[i] 在 i 以上的位都是 0，不会破坏它们；
- 若 res 的第 i 位是 0，异或 basis[i] 让它变 1：这一位收益是 2^i，比所有更低位的总和（2^i - 1）还大，一定划算；
- 若已经是 1，异或后会变 0，不划算。

所以判断条件就是 res ^ basis[i] > res 才异或。高位优先，贪心正确。

## 五、时间复杂度

- 单次 insert / get_max：O(位数)，本题固定 31 次循环，约 O(log V)（V 为值域）
- 用 n 个数建基：O(n * log V)
- 空间：O(位数)

## 六、适用题型

1. 求 n 个数任意子集异或的最大值（本模板直接套用）
   - 例题：[牛客](https://ac.nowcoder.com/acm/contest/133877/B)、[洛谷 P3812【模板】线性基](https://www.luogu.com.cn/problem/P3812)
2. 判断一个数能否由给定数的子集异或得到
   - 把 insert 改成返回 bool：插不进去就说明能被表示
3. 异或第 k 小（进阶）：需要先把基"消元"成每列最多一个 1 的简化形式，本模板未包含，学有余力再补充
4. 异或和为 0 的子集个数（进阶）：2^(n-r) - 1，r 是基的大小
5. 线性基合并、离线删数、可持久化线性基（进阶）

## 七、注意事项

- 循环范围必须和值域匹配：int 范围用 30；long long 值域到 2^60 时用 60~62，同时把数组大小 basis[35] 改成 65 左右；
- 本模板的 insert 是"不消元"写法，求最大/最小/判表示都够用，但求第 k 小必须改用消元写法。

## 代码

```cpp
#include<iostream>
using namespace std;
using ll = long long;

struct LinearBasis
{
	ll basis[35];   // basis[i]：最高位是第 i 位的那个基；数组大小按值域取 35~65
	LinearBasis()
	{
		for (int i = 0; i < 35; i++)basis[i] = 0; // 初始没有基，全部置 0
	}

	void insert(ll x) // 向线性基中插入一个数 x
	{
		for (int i = 30; i > -1; i--) // 从最高位往最低位扫（按题目值域调整范围）
		{
			if ((x >> i) & 1) // x 的第 i 位是 1 才需要处理
			{
				if (basis[i]) x ^= basis[i]; // 这一位已有基：异或消掉这一位，再看低位
				else
				{
					basis[i] = x;   // 这一位还没有基：x 就是新的基
					x ^= basis[i];  // 此时 x 变成 0
					break;          // 插入完成，结束循环
				}
			}
		}
	}

	ll get_max() // 求所有基能异或出的最大值（例题 https://ac.nowcoder.com/acm/contest/133877/B）
	{
		ll res = 0; // 从 0 开始
		for (int i = 30; i > -1; i--) // 从高位往低位贪心
		{
			// 第 i 位是 0 就异或（变 1，收益 2^i 大于所有低位之和），是 1 就跳过
			if ((res ^ basis[i]) > res)res ^= basis[i];
		}
		return res;
	}
};
```

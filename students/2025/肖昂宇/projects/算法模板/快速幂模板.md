# 快速幂（整数幂取模）模板

## 一、要解决的问题

计算 `a^b mod MOD`：b 个 a 相乘，再把结果对 MOD 取余。
比如 `2^10 = 1024`，若 `MOD = 1000`，答案就是 24。
b 可以达到 `10^18` 甚至更大，结果本身也会大到无法直接存储。

## 二、朴素做法为什么不行

最简单的想法：答案 res 从 1 开始，循环 b 次，每次 `res = res * a % MOD`。
这样要循环 b 次。`b = 10^18` 时，即使每秒算 `10^9` 次也要算 30 多年，必定超时。

## 三、核心思想：把指数"折半"，用平方代替连乘

关键观察：指数 b 可以拆成二进制。
例如 `13 = 1101(二进制) = 8 + 4 + 1`，
所以 `a^13 = a^8 * a^4 * a^1`。
而 `a^1、a^2、a^4、a^8` 这几个数可以用"自己平方自己"依次得到：

- `a^2 = (a^1)` 平方
- `a^4 = (a^2)` 平方
- `a^8 = (a^4)` 平方

每次平方只需 1 次乘法，得到 `a^13` 一共只需约 4 步，
比连乘 13 次快得多。b 越大，差距越夸张。

## 四、手把手模拟 a = 2, b = 13（不看取模）

13 的二进制 = 1101，从最低位到最高位依次是 1, 0, 1, 1。
每一位对应"指数里的 2^0、2^1、2^2、2^3 这份要不要乘进答案"：

| 轮次 | b的二进制 | b&1(最低位) | 答案res | 底数a(每轮平方) |
| --- | --- | --- | --- | --- |
| 初始 | | | 1 | a = 2 |
| 第1轮 | 1101 | 1 | res*=2 =2 | a = 4 (=2^2) |
| 第2轮 | 110 | 0 | 不变 =2 | a = 16 (=2^4) |
| 第3轮 | 11 | 1 | res*=16 =32 | a = 256 (=2^8) |
| 第4轮 | 1 | 1 | res*=256 =8192 | a = 65536 |

结束：`res = 2 * 16 * 256 = 2^(1+4+8) = 2^13 = 8192` √
只循环了 4 次，而不是 13 次。
代码里 `b >>= 1` 就是把 b 右移一位，相当于"看下一个二进制位"。

## 五、为什么要取模

`a^b` 增长极快，`2^100` 就有 31 位数，而 `long long` 最多约 19 位数，
中间结果早就溢出了。题目一般会给出模数 MOD（常见 `1e9+7` 或 `998244353`），
要求输出 `a^b mod MOD`。所以我们每乘一次就 `% MOD` 一次，
保证所有中间结果都小于 `MOD^2`（约 `10^18`），不会溢出 `long long`。

## 六、两个版本怎么选

- **fast1 迭代版**：while 循环实现，空间 O(1)，竞赛推荐直接用这个。
- **fast2 递归版**：先递归算出 `a^(b/2)` 再平方，思路更直观，但递归要用栈空间 O(log b)，一般用迭代版就够。

## 七、时间复杂度

循环次数 = b 的二进制位数 ≈ log2(b)，即 O(log b)。
`b = 10^18` 时约 60 次就算完；朴素做法是 O(b) = `10^18` 次。
空间复杂度：迭代版 O(1)，递归版 O(log b)。

## 八、适用题型

1. **模板题**：直接求 `a^b mod p`（如洛谷 P1226）
2. **求逆元**：MOD 为质数时，x 的逆元 = `x^(MOD-2) mod MOD`（费马小定理）
3. **矩阵快速幂**：把"数乘"换成"矩阵乘"，用来求：
   - 斐波那契数列第 n 项（n 可到 `10^18`，如洛谷 P1962）
   - 各类线性递推 / DP 转移的第 n 项
4. 注意：浮点数幂（不取模）直接用 cmath 的 pow 即可，
   但 pow 返回 double，大整数幂用它会丢精度，整数取模必须用本模板。

## 九、易错点

1. 递归版若传入的底数 a 很大（接近 `10^18`）且没有先取模，
   最后 "`res*res` 再乘 a" 会溢出 `long long`（迭代版有 `a %= MOD` 保护）。
   所以递归版开头也要写 `a %= MOD`（本模板已补上，并已暴力验证）。
2. MOD = 1 时答案恒为 0，递归版 `b == 0` 处要返回 `1 % MOD`（本模板已补上）。

## 完整代码

```cpp
#include<iostream>
using namespace std;
using ll = long long;

//竞赛题常给的两种模数，二选一
const ll MOD1 = 1e9 + 7;
const ll MOD2 = 998244353;

//迭代版：时间复杂度O(log b)，空间复杂度O(1)，竞赛最常用
ll fast1(ll a, ll b, ll MOD)
{
	ll res = 1;        //答案初始化为 1（乘法的"起点"，对应 a^0 = 1）
	a %= MOD;          //先把底数缩小到 MOD 以内，防止后面乘法溢出
	while (b)          //只要 b 还有二进制位没处理完就继续
	{
		if (b & 1)res = res * a % MOD; //b 的最低一位是 1：把当前的 a 乘进答案
		a = a * a % MOD;               //底数平方：a -> a^2 -> a^4 -> a^8 ...
		b >>= 1;                       //b 右移一位，处理下一个二进制位
	}
	return res % MOD;  //MOD=1 时也安全；b=0 时返回 1
}

//递归版：时间复杂度O(log b)，空间复杂度O(log b)（递归栈）
ll fast2(ll a, ll b, ll MOD)
{
	if (b == 0)return 1 % MOD;                   //任何数的 0 次方都是 1（取模返回，兼容 MOD=1）
	a %= MOD;                                    //与迭代版同理，防止大底数溢出（新增）
	ll res = fast2(a, b / 2, MOD) % MOD;         //先递归算出 a^(b/2)
	if (b & 1)return (res * res % MOD) * a % MOD; //b 是奇数：平方后再多乘一个 a
	else return res * res % MOD;                  //b 是偶数：直接平方
}
```

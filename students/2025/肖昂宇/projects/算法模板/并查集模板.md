# 并查集 DSU（Disjoint Set Union / Union-Find）

## 一、讲解思路

并查集解决的核心问题：**动态维护若干不相交集合**，支持两个操作：

1. `find(x)`：查询元素 x 属于哪个集合（用该集合的"根"作为代表元标识）
2. `unite(u, v)`：把 u 所在集合与 v 所在集合合并成一个

**关键观察**：每个集合用一棵树来表示，树根就是该集合的代表元。

- `parent[x]` 存 x 的父节点；`parent[x] == x` 说明 x 自己就是根。
- 初始时每个元素自成一个集合：`parent[i] = i`。

**两个核心优化**（都写才能保证近似 O(1)）：

1. **路径压缩**（写在 `find` 里）：
   `find(x)` 递归到根之后，把路径上的每个点直接挂到根上，树被"压扁"，之后的查询接近 O(1)。
2. **按大小合并**（写在 `unite` 里）：
   合并时总是把"小的集合"挂到"大的集合"下面，保证树高不超过 log n，树不会退化成链。
   （也可以按秩合并，效果等价）

> 注意：只做路径压缩、不做按大小合并时，树可能退化成链，find 递归深度可能达到 n，既慢又可能栈溢出（n 很大时），所以两者都建议写。

## 二、时间复杂度

- 单次操作（find / unite）：
  - 路径压缩 + 按大小合并：均摊 O(alpha(n))，alpha 为反阿克曼函数，增长极慢（n <= 2^65536 时 alpha(n) <= 4），实际做题中视作常数 O(1)。
  - 只做路径压缩：均摊 O(log n)。
- 总体：m 次操作共 O(m * alpha(n))，近似 O(m)。
- 空间复杂度：O(n)。

## 三、适用题型

1. 动态连通性：判断两个元素是否在同一集合、合并两个集合（如"朋友的朋友是朋友"这类等价关系传递）
2. 统计连通块数量：连通块数 = 初始 n - 合并成功次数
3. Kruskal 最小生成树：判断边两端是否已连通，避免成环
4. 等价关系 / 分组问题：省份数量、岛屿合并、集合计数
5. 带权并查集、种类并查集（食物链、关押罪犯等）——在本模板基础上扩展

## 四、使用说明

- 下标从 1 开始，`DSU dsu(n)` 创建 n 个元素（1 ~ n）。
- `parent[0]` 会被初始化但不会被使用（无害）。
- 若题目需要查询"集合大小"，直接读 `dsu.sz[dsu.find(x)]`。

## 五、模板代码

```cpp
#include <iostream>
#include <vector>
using namespace std;

struct DSU
{
    vector<int> parent; // parent[x]：x 的父节点；parent[x] == x 表示 x 是根（代表元）
    vector<int> sz;     // sz[x]：以 x 为根的集合大小（只在 x 是根时有意义）

    DSU(int n) // n 个元素，下标 1 ~ n
    {
        parent.resize(n + 1);
        sz.assign(n + 1, 1);                        // 初始每个元素自成一个集合，大小为 1
        for (int i = 0; i <= n; i++) parent[i] = i; // 初始每个点的父节点是自己
    }

    int find(int i) // 返回 i 所在集合的根，并做路径压缩
    {
        if (parent[i] == i) return i;       // 到达根
        return parent[i] = find(parent[i]); // 递归找根，同时把 i 直接挂到根上（路径压缩）
    }

    void unite(int u, int v) // 合并 u 与 v 所在的两个集合
    {
        int i = find(u), j = find(v);       // 先找各自的根
        if (i == j) return;                 // 已在同一集合，无需合并
        if (sz[i] < sz[j]) swap(i, j);      // 按大小合并：保证树高 O(log n)
        parent[j] = i;                      // 小集合挂到大集合下面
        sz[i] += sz[j];                     // 更新合并后的大小
    }
};
```
